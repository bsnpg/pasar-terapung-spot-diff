**Pasar Terapung — Spot the Difference.** An Indonesian floating market, drawn
entirely in code: 3 scenes (Pasar Pagi, Pasar Siang, Lentera Malam), 7 fair
differences each — removed, recoloured, moved, resized, flipped or added.
Click a difference on either picture to ring it; wrong clicks cost 3 seconds.
Timer, score, streak multiplier, 3 hints, a hover magnifier, keyboard
shortcuts (H hint · P pause · R restart · 1-3 scene · M sound) and WebAudio
bleeps. All art is procedural Canvas 2D — no images, no network, fully
deterministic: two runs of the program produce byte-identical output.

## Run it

```sh
node main.ts
```

Serve the game locally with `node serve.ts`, then open http://localhost:8080.
